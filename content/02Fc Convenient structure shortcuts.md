# Diagonal matrices
$D=diag(d_{1},\dots)\to D^{-1}=diag\left( \frac{1}{d_{1}},\dots \right)$
Just inverse each diagonal number.

! It's clear that if any number on the diagonal is zero, that row/column is zero, so the determinant is zero and the matrix is not invertible.

# Triangular matrices

Because triangular matrices alread have an isolated variable, gaussian elimination method is super fast.

# Orthogonal Matrices

$A^{-1}=A^{t}$

By definition, a matrix is orthogonal if $A^{t}A=AA^{t}=I$
